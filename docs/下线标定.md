下线标定用于校准雷达安装角度与目标参考方向，使雷达输出结果与实验平台坐标保持一致。标定通常在固定工位或相对稳定的实验环境中完成。

###  标定准备

标定前请准备：

| 类型   | 说明                 |
| ---- | ------------------ |
| 雷达设备 | CTSAI-A100  |
| 标定目标 | 标定板、反射板或三角反射锥      |
| 控制电脑 | 运行 RadarTools 软件 |
| 通信设备 | USB-CAN FD 盒       |
| 电源   | 12V DC 电源          |
| 固定装置 | 雷达支架、目标支架或实验平台     |

### 标定工位搭建

按照标定示意，将雷达和标定目标布置在同一测试区域中。

布置时请确认：

* 雷达正对标定目标。
* 标定目标位于雷达有效探测范围内。
* 雷达与目标之间无遮挡。
* 雷达前方尽量避免强反射干扰物。
* 雷达固定稳定，不产生明显晃动。
* 标定目标位置清晰、稳定、可重复。

标定目标可使用反射板或三角反射锥。标定过程中应保持目标位置固定。

### 启动标定工具

当前仓库未包含独立的 RadarTools 标定程序。开始标定前，请先从设备供应方获取与 CTSAI-A100 匹配的标定工具和版本说明。

###  执行标定

完成设备连接后，在标定工具中执行标定流程。

基础流程如下：

1. 雷达上电。
2. 连接 USB-CAN FD 设备。
3. 启动 RadarTools 标定工具。
4. 确认雷达数据正常输出。
5. 按标定工位要求摆放标定目标。
6. 在标定工具中执行标定。
7. 等待标定完成。
8. 检查标定结果。
9. 保存标定参数。

标定完成后，可重新进入点云或目标输出界面，确认目标角度、位置和跟踪结果是否符合预期。

### 标定注意事项

标定过程中请注意：

* 标定目标应尽量处于雷达视场中心区域。
* 标定目标附近不应放置强反射干扰物。
* 标定时保持雷达和目标稳定。
* 标定完成后不要立即移动雷达安装位置。
* 如雷达安装位置、角度或支架发生变化，应重新标定。
* 若标定结果异常，请重新检查接线、目标位置和工位环境。
