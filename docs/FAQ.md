> 如有疑惑欢迎前往社区论坛发帖提出您的问题!

### RadarTools 点击 Start 后没有数据显示？

请检查：

* 雷达是否正常供电。
* CAN-H / CAN-L 是否接反。
* USB-CAN FD 驱动是否安装成功。
* 设备管理器中是否识别 USB-CAN FD 设备。
* 上位机参数配置是否正确。
* 雷达是否处于正常工作状态。

###  设备管理器看不到 USB-CAN FD 设备？

请检查：

* USB 数据线是否正常。
* USB-CAN FD 盒是否连接电脑。
* 驱动是否按系统位数正确安装。
* 是否需要重新插拔设备。
* 是否需要更换 USB 接口。

### 上位机能启动，但没有目标点？

请检查：

* 雷达前方是否有有效目标。
* 雷达安装方向是否正确。
* 波形模式是否适合当前测试距离。
* 是否存在遮挡。
* 是否处于过近或过远的测试距离。
* 是否已经正确点击 `Start`。

### 点云采集后找不到数据文件？

请检查：

* 是否已经点击点云采集按钮。
* 是否点击 `Stop` 结束采集。
* `tools/RadarTools_Release/data/` 目录是否存在。
* 上位机是否具有当前目录写入权限。

### ADC 采集后没有生成数据？

请检查：

* 是否已先点击 `Start`。
* ADC 采集界面参数是否已填写。
* 采集目录是否存在。
* 当前用户是否有写入权限。
* 雷达数据流是否正常输出。
* 远波 / 近波配置是否与采集设置一致。

### Matlab 分析 ADC 数据时报错？

请检查：

* ADC 数据是否已拷贝到 `examples/matlab-adc-processing/data/`。
* 是否配置了正确的数据文件路径。
* 4 个接收通道文件名是否填写正确。
* 远波 / 近波配置文件是否选择正确。
* Matlab 当前工作路径是否在示例工程目录下。

###  Python 脚本运行时报缺少依赖？

请执行：

```bash
python -m pip install pandas matplotlib numpy
```

若仍然报错，请确认当前终端使用的 Python 环境与安装依赖的 Python 环境一致。

###  Python 可视化没有显示结果？

请检查：

* 输入 CSV 路径是否正确。
* CSV 文件是否为空。
* 字段名是否与脚本中的读取字段一致。
* 数据中是否包含有效目标。
* matplotlib 是否正常安装。

### 标定结果异常怎么办？

请检查：

* 标定目标是否位于雷达有效视场内。
* 目标与雷达之间是否无遮挡。
* 周围是否有强反射物。
* 雷达和目标是否固定稳定。
* 标定工具是否使用正确版本。
* 是否在移动雷达后未重新标定。
