进入 Python 示例目录：

```bash
cd Python雷达可视化工具示例
```

运行示例脚本：

```bash
python radarViewer.py
```

脚本启动后会打开文件选择窗口。可以选择仓库附带的示例数据：

```text
负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv
```

### 示例数据字段

RawTarget 示例数据通常包含目标检测与跟踪相关字段。不同版本字段可能存在差异，以下为常见字段说明：

| 字段            | 说明          |
| ------------- | ----------- |
| frame_id      | 帧编号         |
| timestamp     | 时间戳         |
| target_id     | 目标编号        |
| range_m       | 目标距离，单位 m   |
| velocity_mps  | 相对速度，单位 m/s |
| azimuth_deg   | 水平角，单位 °    |
| elevation_deg | 俯仰角，单位 °    |
| x             | 笛卡尔坐标 X     |
| y             | 笛卡尔坐标 Y     |
| z             | 笛卡尔坐标 Z     |
| snr           | 信噪比         |
| rcs           | 雷达散射截面积     |
| track_state   | 跟踪状态        |

实际字段以仓库中的示例 CSV 为准。

### 可视化功能

Python 示例工具提供以下参考能力：

* 读取雷达 CSV 数据
* 对目标点进行基础筛选
* 绘制点云分布
* 显示目标聚类结果
* 绘制目标轨迹
* 按帧回放目标变化
* 辅助分析目标距离、速度和角度变化

该示例适合用于快速理解雷达输出数据结构，并作为后续算法开发的起点。
