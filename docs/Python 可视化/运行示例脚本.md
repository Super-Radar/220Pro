进入 Python 示例目录：

```bash
cd Python雷达可视化工具示例
```

运行示例脚本：

```bash
python radarViewer.py
```

脚本启动后会打开文件选择窗口。可以选择仓库附带的示例数据：

```text
负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv
```

### 示例数据字段

仓库附带的 RawTarget CSV 使用 RadarTools 导出字段。脚本会读取以下核心字段：

| 字段 | 说明 |
| --- | --- |
| `ObjId` | 当前帧中的目标编号 |
| `range` | 目标距离，单位为 m |
| `speed` | 相对径向速度，单位为 m/s |
| `angle` | 目标方位角，单位为 ° |
| `snr` | 信噪比，单位为 dB |
| `X` | 目标 X 坐标，单位为 m |
| `Y` | 目标 Y 坐标，单位为 m |
| `RCS` | 雷达散射截面积 |

RadarTools 结构化导出文件还包含 `START,FrameNb:<编号>` 帧标记和时间戳元数据行。
它们不是普通目标数据列。脚本解析这些元数据后，会为当前帧生成 `FrameNb` 和
`Timestamp` 信息。

不同 RadarTools 版本可能增加其他字段。输入文件应保留上表中的全部核心字段，
才能完整使用筛选、跟踪和绘图功能。实际字段名称区分大小写，
请以仓库中的示例 CSV 首行为准。

### 可视化功能

Python 示例工具提供以下参考能力：

* 读取雷达 CSV 数据
* 对目标点进行基础筛选
* 绘制点云分布
* 显示目标聚类结果
* 绘制目标轨迹
* 按帧回放目标变化
* 辅助分析目标距离、速度和角度变化

该示例适合用于快速理解雷达输出数据结构，并作为后续算法开发的起点。
