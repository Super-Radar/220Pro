Python 可视化示例用于读取雷达输出数据，并进行基础可视化分析。示例脚本可用于信号筛选、跟踪算法、聚类显示和轨迹绘制等功能验证。

### Python 环境要求

请先确认电脑已安装 Python 环境。

推荐使用：

```text
Python 3.8+
```

安装依赖库：

```bash
python -m pip install pandas matplotlib numpy
```

### 示例工程目录

Python 可视化示例位于：

```text
examples/python-visualization/
```

示例数据位于：

```text
sample-data/visualization/
```

示例 CSV 文件可以使用仓库中的 RawTarget 数据，例如：

```text
sample-data/visualization/example_RawTarget.csv
```
