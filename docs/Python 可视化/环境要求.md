Python 可视化示例用于读取雷达输出数据，并进行基础可视化分析。示例脚本可用于信号筛选、跟踪算法、聚类显示和轨迹绘制等功能验证。

### Python 环境要求

请先确认电脑已安装 Python 环境。

推荐使用：

```text
Python 3.8+
```

安装依赖库：

```bash
python -m pip install pandas matplotlib numpy
```

### 示例工程目录

Python 可视化示例位于：

```text
Python雷达可视化工具示例/
```

示例数据与脚本位于同一目录：

```text
Python雷达可视化工具示例/
```

示例 CSV 文件可以使用仓库中的 RawTarget 数据，例如：

```text
Python雷达可视化工具示例/负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv
```
