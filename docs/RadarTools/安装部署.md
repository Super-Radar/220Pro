###  获取 RadarTools

RadarTools [Github下载链接](https://github.com/Super-Radar/CTSAI-A100)


进入目录后，运行：

```text
RadarTools_V1.4.6.3.exe
```

###  启动前检查

启动上位机前，请确认：

* 雷达已正常供电。
* CAN-FD 接线正确。
* USB-CAN FD 驱动已安装成功。
* USB-CAN FD 设备已被系统识别。
* 上位机软件已放置在完整目录中运行，不要单独移动 `.exe` 文件。

###  连接雷达并启动数据流

打开 RadarTools 后，按照界面中的设备参数进行配置。确认配置无误后，点击：

```text
Start
```

点击 `Start` 后，上位机会开始接收雷达数据。正常连接后，可以在界面中看到：

* 原始点
* 跟踪点
* 目标列表
* 距离、速度、角度等目标信息

若点击 `Start` 后没有数据输出，请检查：

* 雷达是否供电。
* CAN-H / CAN-L 是否接反。
* USB-CAN FD 设备是否正常识别。
* 上位机端口与通道配置是否正确。
* 雷达是否处于正确工作模式。
