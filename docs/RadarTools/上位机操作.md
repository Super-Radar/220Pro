# 1. 主页面概览

RadarTools 主页面用于完成雷达设备连接、点云采集、目标显示、ADC 数据采集、数据回放以及标定等功能，是软件的主要工作界面。

软件启动并建立通信连接后，可实时查看雷达检测结果，并根据不同开发需求进行数据采集、目标分析和功能验证。

主页面主要由以下几个区域组成：

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 提供点云采集、ADC 采集、标定、数据回放、远波/近波切换、恢复布局以及通信控制等功能入口。 |
| 左侧显示面板 | 原始点显示区域，用于展示雷达输出的原始检测点（Raw Point）。 |
| 右侧显示面板 | 跟踪点显示区域，用于展示经过目标跟踪后的目标结果（Track Target）。 |
| 中间/右侧数据列表 | 实时显示目标 ID、距离、速度、角度、SNR、RCS 等目标属性信息。 |
| 底部筛选栏 | 控制点类型、运动方向、真值、通道、区域等显示开关，便于按需筛选数据显示内容。 |



# 2. 顶部工具栏功能

顶部工具栏提供了 RadarTools 的主要操作入口，包括设备通信、点云采集、ADC 数据采集、数据回放及标定等功能。

| 功能 | 说明 |
|------|------|
| 点云采集 / 停止采集 | 开始或停止点云数据采集，并保存至本地。 |
| ADC采集 | 打开 ADC 数据采集页面，用于采集 ADC、FFT 等底层数据。 |
| 售后 / 下线标定 | 打开标定相关窗口，用于设备标定及调试。 |
| 回放 | 进入点云数据回放模式，加载历史采集数据进行离线分析。 |
| 远波 | 切换至远波工作模式，适用于中远距离目标探测及场景验证。 |
| 近波 | 切换至近波工作模式，适用于近距离目标探测及室内测试。 |
| 回到初始布局 | 同时恢复原始点和跟踪点两个显示面板到软件启动时的默认视图。 |
| CAN-FD / CAN | 选择通信设备类型。 |
| CAN通道 | 选择当前通信所使用的 CAN 通道。 |
| 波特率 | 设置 CAN 仲裁段波特率。 |
| 数据域波特率 | 设置 CAN-FD 数据域波特率。 |
| Start / Stop | 建立或关闭与雷达设备之间的通信连接。 |

建立通信前，请确认通信设备类型、CAN 通道、波特率及数据域波特率配置正确。点击 **Start** 后，软件开始接收雷达实时数据；点击 **Stop** 可停止通信。



# 3. 主显示面板操作

RadarTools 支持对显示区域进行缩放、平移及视图恢复，方便开发者观察不同距离和角度范围内的目标数据。

| 操作 | 效果 |
|------|------|
| 鼠标左键拖动 | 平移当前显示区域。 |
| 鼠标滚轮 | 上下滚动视图。 |
| Shift + 鼠标滚轮 | 左右滚动视图。 |
| Ctrl + 鼠标滚轮 | 以鼠标所在位置为中心进行缩放。 |
| 右键双击当前面板 | 将当前面板恢复到初始视图。 |
| 点击 **回到初始布局** | 同时恢复原始点和跟踪点两个面板到软件启动时的初始视图。 |

> 缩放、平移及滚动仅改变当前显示区域，不会修改雷达原始数据或目标数据。



# 4. 点和目标显示说明

RadarTools 实时显示雷达检测结果，包括原始检测点（Raw Point）和目标跟踪结果（Track Target）。

为了便于开发者快速识别目标状态，不同点和目标采用不同颜色及图形进行显示。颜色和形状可能因协议版本不同存在少量差异，以下为当前版本的通用说明。

## 4.1 原始点颜色含义

原始点颜色主要由目标运动状态及异常标记决定。

| 颜色 / 形状 | 含义 |
|-------------|------|
| 白色空心方框 | 未知状态点。 |
| 红色空心方框 | 运动点。 |
| 灰色空心方框 | 静止点。 |
| 青色空心三角形 | 角度异常点。 |
| 紫色空心三角形 | 通用异常标记点。 |

原始点主要用于点云分析、目标聚类、环境感知及算法研究等场景，能够反映雷达最原始的检测结果。

## 4.2 跟踪点颜色含义

跟踪点（Track Target）为雷达经过目标关联、状态估计和目标跟踪算法后的输出结果，更适用于目标跟踪、轨迹分析及应用验证。

跟踪点颜色与具体协议版本及雷达类型有关，不同产品的状态枚举可能略有差异。当前版本中，各颜色的常见含义如下：

| 颜色 | 常见含义 |
|------|----------|
| 红色 | 运动目标、来向目标或接近目标。 |
| 黄色 | 停止目标，或由运动状态切换为静止状态的目标。 |
| 绿色 | 静止目标。 |
| 灰色 | 未知、保留、未分类目标，或部分协议中的静止目标。 |
| 白色 | 横穿目标。 |

说明：

1. **黄色** 在多数协议版本中用于表示 **Stopped（停止目标）**。
2. **绿色** 主要用于将 **Stationary（静止目标）** 单独区分的协议版本。
3. **灰色** 常用于 **Unknown（未知）**、**Reserved（保留）** 等状态，部分协议也会使用灰色表示静止目标。
4. 实际颜色显示可能因协议版本升级而发生变化，请以当前软件版本显示为准。



## 4.3 跟踪点形状含义

除了颜色之外，RadarTools 还会通过不同图形表示目标类型，方便快速识别不同类别目标。

| 形状 | 常见含义 |
|------|----------|
| 点 | 点目标。 |
| 空心方框 | 未知、未分类、保留或默认目标。 |
| 实心方框 | 卡车类目标。 |
| 实心圆 | 轿车类目标。 |
| 空心椭圆 | 摩托车、自行车类目标。 |
| 实心椭圆 | 行人类目标。 |

不同协议版本支持的目标分类能力可能有所不同，当协议未输出目标类别时，软件通常使用默认图形进行显示。



# 5. 底部筛选项

底部筛选栏用于控制不同类型目标及辅助信息的显示状态，便于开发者根据实际需求快速筛选关注的数据，提高观察和分析效率。

| 功能 | 说明 |
|------|------|
| 不显示绿点 | 隐藏绿色目标点。 |
| 相对静止 | 显示或过滤相对静止目标。 |
| 相对来向 | 显示或过滤相对来向目标。 |
| 相对去向 | 显示或过滤相对去向目标。 |
| 真值 | 显示真值目标。 |
| CH1 / CH2 | 控制不同通道目标的显示。 |
| Area | 显示配置区域框。 |
| ACC | 显示 ACC 相关信息。 |
| 驻留 | 控制原始点驻留显示。 |

开发者可根据当前测试场景灵活开启或关闭各筛选项，以获得更加清晰的数据展示效果。



# 6. 数据列表说明

主页面右侧数据列表用于实时显示雷达输出的目标信息，便于开发者查看目标状态及分析检测结果。

常见字段说明如下：

| 字段 | 说明 |
|------|------|
| ID | 目标编号。 |
| R[m] | 目标距离，单位 m。 |
| V[m/s] | 目标速度，单位 m/s。 |
| A[deg] | 目标角度，单位 °。 |
| Mag | 幅值。 |
| SNR | 信噪比（Signal to Noise Ratio）。 |
| RCS | 雷达散射截面积（Radar Cross Section）。 |
| HA | 高度角（Height Angle）。 |

不同协议版本可能增加或减少部分字段，具体显示内容以当前软件版本及雷达协议为准。



# 7. ADC 采集页面

ADC 采集页面用于采集雷达底层 ADC 数据、FFT 数据及历史数据回放，是进行雷达信号处理、算法研究及离线分析的重要功能模块。

开发者可通过该页面完成 ADC 数据采集、采集参数配置、历史数据导入及数据管理等操作。

点击主页面顶部工具栏中的 **ADC采集** 按钮即可进入 ADC 采集页面。



## 7.1 当前页面交互

ADC 采集页面提供以下交互功能：

1. 页面会自动记忆上一次使用的 **RxCH、FrameType、Radar(dbgId)、DataType、文件名** 及 **采集次数** 等参数。
2. 参数配置完成后，直接点击 **开始采集** 即可，程序将在需要时自动切换进入 ADC 模式。
3. 页面下方 **Time** 与 **RFFT** 图表当前默认隐藏，不参与实时刷新，以降低界面重绘开销，提高采集效率。
4. 采集文件按 **文件包目录** 进行保存，不再平铺存放于 `adcData/` 根目录。



## 7.2 参数区说明

ADC 采集页面参数说明如下：

| 控件 | 说明 |
|------|------|
| FrameType | 选择 Profile 编号：0 / 1 / 2 / 3 / ALL。该参数表示当前 Profile，不直接对应远波或近波工作模式。 |
| RxCH | 选择接收通道：0 / 1 / 2 / 3 / ALL。 |
| Sample_N | 当前采样点数，完成采集或导入历史文件后自动回填。 |
| Chirp_N | 当前 Chirp 数量，完成采集或导入历史文件后自动回填。 |
| MIMO | 用于 RFFT 数据组织方式，当前图表区域默认隐藏。 |
| 状态 | 显示当前采集状态。 |
| 文件名 | 设置采集数据保存目录及文件名前缀。 |
| 数据回放 | 选择历史 `.txt` 数据文件。 |
| Radar(dbgId) | 选择 ADC 调试 CAN ID，例如 `0x145`、`0x7A0`。 |
| DataType | 选择采集数据类型：ADCData、1DFFTData、2DFFTData。 |
| 采集次数 | 设置连续执行 **开始采集** 的次数，默认值为 1。 |



## 7.3 按钮说明

ADC 页面主要包含以下操作按钮：

| 按钮 | 说明 |
|------|------|
| 开始采集 | 根据当前参数配置启动数据采集。 |
| 点击选择回放文件 | 导入历史 `.txt` 文件进行数据回放。 |

当前版本保留了 **进入 ADC 模式** 的内部逻辑，但页面默认不再单独提供该按钮。常规使用过程中，仅需完成参数配置后直接点击 **开始采集**，程序将自动完成 ADC 模式切换及数据采集流程。

## 7.4 采集流程

ADC 数据采集流程如下：

1. 选择 **Radar(dbgId)**、**FrameType**、**RxCH** 和 **DataType**。
2. 输入采集文件名称，并根据需要设置 **采集次数**。
3. 点击 **开始采集**。
4. 若当前设备尚未进入 ADC 模式，程序会自动发送进入 ADC 模式指令，随后发送采集指令，无需手动切换。
5. 每完成一轮采集，程序将在同一个文件包目录下生成对应的数据文件。
6. 当 **采集次数** 大于 1 时，程序将按照当前配置自动重复执行采集流程，直到所有轮次完成。

整个采集过程中，可通过页面右侧日志窗口实时查看采集状态及执行过程。



## 7.5 回放交互

RadarTools 支持导入历史 ADC 数据进行离线查看，便于开发者分析采集结果或验证数据。

操作流程如下：

1. 点击 **点击选择回放文件**。
2. 选择历史采集生成的 `.txt` 数据文件。
3. 软件自动解析文件头中的 **接收通道（RxCH）**、**Sample_N** 和 **Chirp_N** 等参数，并自动回填至当前页面。
4. 当前版本中，底部 **Time** 与 **RFFT** 图表默认隐藏，因此回放过程中不会显示对应曲线。

通过数据回放功能，可快速确认历史采集数据是否完整，并为后续 MATLAB、Python 或其他算法平台的数据处理提供验证依据。



## 7.6 日志和进度

ADC 采集过程中，RadarTools 将实时输出采集日志及当前执行进度，方便开发者快速定位问题。

| 区域 | 说明 |
|------|------|
| 右侧日志框 | 实时显示进入 ADC 模式、开始接收、接收完成、保存路径及错误信息等日志。 |
| 采集进度 | 显示当前数据接收进度及完成情况。 |
| 状态栏 | 显示当前采集轮次及软件运行状态。 |

建议在采集过程中持续关注日志输出，如出现异常，可根据提示信息检查通信状态或参数配置。



## 7.7 保存规则

所有采集结果默认保存在 RadarTools 运行目录下的 **adcData/** 文件夹中。

每次点击 **开始采集** 后，软件都会自动创建一个新的文件包目录，目录结构如下：

```text
adcData/
└── {prefix}{文件名}_{时间戳}/
```

其中，目录前缀由当前 **DataType** 决定：

| DataType | 目录前缀 |
|----------|----------|
| ADCData | adc_ |
| 1DFFTData | 1dfft_ |
| 2DFFTData | 2dfft_ |

例如：

```text
adcData/
└── adc_Test_20260708153025/
```

每轮采集生成的数据文件命名格式如下：

```text
run_001_Pf1_Rx0.txt
```

各字段含义如下：

| 片段 | 含义 |
|------|------|
| run_001 | 第 1 轮采集。 |
| Pf1 | 当前 Profile 编号。 |
| Rx0 | 当前接收通道。 |

当 **采集次数** 大于 1 时，每轮采集都会生成对应的数据文件，便于后续批量分析与结果管理。


# 8. 常见操作建议

为了获得更加稳定的数据采集和使用体验，建议按照以下方式进行操作：

| 场景 | 建议操作 |
|------|----------|
| 实时采集前 | 检查 CAN / CAN-FD 类型、通信通道、波特率及数据域波特率配置是否正确。 |
| 点显示过于密集 | 使用底部筛选项过滤部分目标，或通过缩放功能查看局部区域。 |
| 找不到目标 | 点击 **回到初始布局** 恢复默认视图。 |
| 查看历史 ADC 数据 | 在 ADC 页面点击 **点击选择回放文件** 导入历史数据。 |
| ADC 采集失败 | 检查 **Radar(dbgId)**、通信连接状态及设备工作状态后重新采集。 |
| 点云采集完成后验证数据 | 建议先通过 RadarTools 回放确认数据完整性，再进行算法分析。 |
| 多轮数据采集 | 建议合理设置 **采集次数**，方便连续采集多个数据样本。 |



# 9. 注意事项

为确保 RadarTools 正常运行及采集数据的完整性，请注意以下事项：

1. 缩放、平移及视图滚动仅影响当前显示范围，不会修改雷达原始数据或目标数据。
2. 点颜色及目标形状可能因协议版本不同存在差异，本文档以当前版本常见映射关系为准。
3. ADC 采集数据默认采用 `.txt` 格式保存。
4. 实时采集过程中仍可正常使用缩放、平移及 **回到初始布局** 等显示操作，不影响数据采集。
5. **FrameType** 用于选择当前 **Profile**，并非顶部工具栏中 **远波 / 近波** 按钮的直接对应关系。
6. 建议在开始采集前确认通信连接正常，并确保雷达设备已进入工作状态。
7. 请勿在采集过程中断开设备连接或关闭软件，以免造成数据文件不完整。
8. 若软件出现通信异常，可先停止通信，再重新建立连接后继续采集。
9. 建议定期整理 `adcData/` 目录中的历史采集数据，避免长期累积占用大量磁盘空间。
10. 不同软件版本可能新增或调整部分功能，请以当前发布版本为准。
