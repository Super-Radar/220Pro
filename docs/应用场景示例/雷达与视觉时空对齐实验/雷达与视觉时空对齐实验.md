# CTSAI-A100 雷达与视觉时空对齐实验

> 当前状态：实验设计。本文只讨论研究和数据验证流程，不宣称已经实现量产级传感器融合能力。

## 1. 场景背景

毫米波雷达可以输出目标距离、径向速度、角度或点云信息，相机则提供图像坐标和外观信息。两种传感器的观测空间、帧率和时间基准不同，如果没有先验证时间同步、坐标变换和关联误差，直接把雷达点画到图像上很容易得到看似合理但不可复现的结果。

本实验面向室内走廊或实验室开阔区域，使用 CTSAI-A100 与一台固定相机记录单人或小车的受控运动。重点不是训练识别模型，而是建立一条可审计的基础链路：定义坐标系、采集同步事件、估计时间偏移、完成外参标定、将雷达观测投影到相机坐标，并用独立测试序列评价对齐误差。

## 2. 适合采集的数据类型

- RadarTools 输出的原始目标、跟踪目标或 CAN 数据，保留设备时间戳和配置文件；
- 相机视频或逐帧图像，保留原始帧序号、采集时间和内参信息；
- 雷达与相机的安装位置、朝向、高度和固定方式；
- 标定目标在地面坐标系中的实测位置，以及每次移动的开始、停止和方向记录；
- 可选 ADC 数据，用于研究雷达检测链对时间偏移和目标可见性的影响。

相机画面可能包含可识别人员或环境信息。公开数据前应取得授权并进行脱敏；不需要公开的视频应只保存必要的派生标注。

## 3. 坐标系与实验对象

建议至少定义三个坐标系：雷达坐标系 \(R\)、相机坐标系 \(C\) 和地面参考坐标系 \(G\)。所有坐标系必须记录原点、轴方向、单位和右手/左手约定。雷达到相机的刚体变换写为

$$
\mathbf p_C=\mathbf R_{CR}\mathbf p_R+\mathbf t_{CR},
$$

其中 \(\mathbf R_{CR}\) 为旋转矩阵，\(\mathbf t_{CR}\) 为平移向量。若需要投影到图像像素，还要使用相机内参和畸变模型。外参只能由实测标定数据估计，不能根据设备照片或目测角度填写。

建议使用带明显雷达反射面的平面标定板、小推车或固定在支架上的角反射器作为标定目标。目标分别放置在近、中、远距离及画面左右两侧，避免所有点都集中在一条直线上。

## 4. 受控测试矩阵

| 编号 | 场景 | 主要用途 |
|---|---|---|
| F0 | 空场同步采集 | 检查背景输出和时间戳连续性 |
| F1 | 标定目标在多个静态位置停留 | 估计并验证空间外参 |
| F2 | 单目标沿雷达径向靠近 | 估计时间偏移并检查距离趋势 |
| F3 | 单目标沿雷达径向远离 | 验证速度符号和时间对齐 |
| F4 | 单目标横向穿过视场 | 检查低径向速度下的空间关联 |
| F5 | 目标执行“移动—停止—继续移动” | 观察两种传感器的延迟和目标保持差异 |
| F6 | 两目标交叉运动 | 检查错误关联和轨迹交换 |

每组场景应至少重复三次，并在独立序列上进行最终验证。用于估计时间偏移和外参的样本不能全部再次用于报告验证误差。

## 5. 时间同步方法

优先使用硬件触发或统一时钟。若设备暂时只支持各自记录时间戳，可使用可重复的运动事件估计剩余时间偏移，例如让角反射器快速进入雷达视场并在相机画面中的地面标记处停止。对候选偏移 \(\Delta t\) 比较雷达距离变化率与视觉轨迹径向分量，选择误差最小的偏移，并在另一段序列上复核。

时间戳必须保留原始值，派生的对齐时间另存新列。禁止直接覆盖原始时间或按行号硬配对，因为掉帧、重复帧和不等帧率会使行号失去物理意义。可使用最近邻配对，但要设置最大允许时间差：

```python
from bisect import bisect_left

def nearest_frame(radar_time, camera_times, max_gap_s=0.05):
    i = bisect_left(camera_times, radar_time)
    candidates = [j for j in (i - 1, i) if 0 <= j < len(camera_times)]
    if not candidates:
        return None
    j = min(candidates, key=lambda k: abs(camera_times[k] - radar_time))
    return j if abs(camera_times[j] - radar_time) <= max_gap_s else None
```

`max_gap_s` 应根据实际帧率和允许延迟设定，上述数值只是代码默认值，不是 CTSAI-A100 的性能指标。

## 6. 空间标定与关联流程

1. 完成相机内参标定，保存图像尺寸、焦距、主点和畸变参数；
2. 固定雷达与相机，测量两者相对安装位置并记录初值；
3. 在多个已知地面位置采集标定目标，提取雷达目标点和相机目标中心；
4. 用稳健方法估计 \(\mathbf R_{CR}\) 与 \(\mathbf t_{CR}\)，剔除原因明确的错误匹配；
5. 在未参与拟合的 F1 记录上计算投影误差；
6. 对 F2～F6 执行时间配对、坐标变换和目标关联；
7. 同时保留匹配成功、未匹配雷达点和未匹配视觉目标，避免只展示成功样本。

关联时可组合时间差、投影像素距离、地面位置距离和运动方向一致性。阈值必须由训练/调参序列确定，再固定到验证序列。对于多个候选目标，应使用一对一匹配，不能让同一个视觉框同时解释多个独立雷达轨迹。

推荐工具链为 CTSAI-A100、RadarTools、固定支架和标定目标；OpenCV 可用于相机内参与投影；NumPy、Pandas 和 Matplotlib 可用于时间对齐、记录检查和结果绘图；MATLAB 可用于 ADC 与距离—多普勒处理。任一工具生成的中间文件都应记录版本、参数和输入文件哈希。

## 7. 建议评价量

- 时间配对覆盖率：在最大允许时间差内找到相机帧的雷达记录比例；
- 时间残差：配对后两种传感器时间差的中位数、95 分位数和最大值；
- 静态重投影误差：独立标定点在图像中的像素误差；
- 地面位置误差：变换后的雷达位置与人工测量位置的欧氏距离；
- 关联准确性：正确匹配、错误匹配、雷达未匹配和视觉未匹配的数量；
- 轨迹连续性：完整动作期间保持正确关联的时间比例；
- 跨场景稳定性：F2～F6 是否需要重新调整阈值才能工作。

结果应按场景和重复序号分别报告，不应只给平均值。像素误差受目标框标注方式和成像分辨率影响，不能单独用来说明三维定位性能。

## 8. 注意事项与能力边界

- 传感器支架移动、相机变焦或重新对焦后都可能使外参失效，需要重新标定；
- 雷达角度、点云或跟踪结果的含义必须以实际配置和公开接口为准；缺少阵列、MIMO 或标定元数据时，不应虚构精确三维坐标；
- 相机只能作为经说明的参考传感器，人工标注也存在误差；
- 横向运动的径向速度可能接近零，雷达与视觉可见性不同，未匹配不一定代表算法故障；
- 多径可能把雷达点投影到看似合理的图像区域，必须结合空场和重复实验识别；
- 本实验用于研究时空对齐，不构成安全监控、人员识别或自动驾驶功能证明；
- 发布视频、图像、日志和标注前必须完成隐私检查，不公开人脸、姓名、工牌或精确场所信息。

## 9. 交付建议

完整贡献可以包含坐标系定义图、安装与复测记录、时间戳字段说明、标定数据清单、外参文件、对齐脚本、验证指标和失败样本。没有实测数据时，应明确标记为“实验方案”；仿真投影图只能用于检查数学链路，不能替代 CTSAI-A100 与相机的现场标定结果。
