# 仓储机器人货架通道动态障碍物感知

> 当前状态：实验方案。本文用于指导数据采集和算法验证，不包含未经现场测试的性能结论。

## 1. 场景背景

仓储机器人在货架通道内运行时，会遇到金属货架、托盘、立柱等强静态反射体，也可能遇到行人、手推车、临时放置的纸箱和其他低速机器人。窄通道中的遮挡、多径和近距离强反射容易造成目标点漂移、短时丢失或假目标，因此适合作为 CTSAI-A100 的受控感知实验场景。

本实验不把雷达输出直接等同于可用于安全停车的工程级结果。目标是建立一组可复现的研究流程：记录静态背景，采集不同障碍物的靠近、远离、横穿和停留数据，比较原始目标、跟踪目标与 ADC 离线处理结果，并分析不同安装位置和通道布置对观测结果的影响。

## 2. 场景布置与数据类型

建议选择一段可以封闭管理的直线通道，将雷达固定在机器人前端模拟支架上。采集前使用卷尺记录通道宽度、货架间距、雷达安装高度、俯仰角、目标起点与终点；雷达安装完成后先采集空场基线，再开始有人或小车参与的动态实验。

建议至少采集以下数据：

- RadarTools 输出的原始目标、跟踪目标或 CAN 记录，用于检查距离、径向速度、角度和轨迹连续性；
- ADC 原始数据及对应配置文件，用于 Range FFT、Doppler FFT、距离—多普勒图、MTI 和基础 CFAR 实验；
- 场地尺寸、雷达姿态、障碍物类型、人工动作时间和重复序号，用于建立可追溯的实验记录；
- 可选的固定机位视频，仅作为人工真值参考，公开前需要处理人脸、工牌和仓储标签等隐私信息。

建议的受控测试组如下：

| 编号 | 场景 | 研究目的 |
|---|---|---|
| W0 | 空通道 | 建立货架和地面的静态背景基线 |
| W1 | 单人沿通道靠近 | 检查距离趋势和轨迹连续性 |
| W2 | 手推车沿通道远离 | 比较不同目标的径向速度输出 |
| W3 | 纸箱放在通道中央 | 观察静止障碍物在不同处理链中的表现 |
| W4 | 行人从侧向开口横穿 | 检查低径向速度与短时遮挡 |
| W5 | 两个目标前后通过 | 观察轨迹合并、分裂和遮挡恢复 |
| W6 | 通道一侧增加金属反射板 | 对比强多径条件下的假目标变化 |

每组场景至少重复三次。失败、中断或动作偏离的记录也应保留并在备注中说明，不能只选择最理想的一次作为结果。

## 3. 可研究的问题

1. 金属货架和立柱在空场距离谱及距离—多普勒图中形成哪些稳定峰值；
2. 行人、手推车和纸箱的输出在距离、速度、点数和轨迹连续性上有何差异；
3. 一阶或二阶 MTI 对静态背景的抑制效果如何，是否同时削弱停留目标；
4. 侧向横穿时径向速度接近零，单纯速度阈值是否会漏掉目标；
5. 两目标前后通过或相互遮挡时，轨迹是否出现交换、合并或长时间中断；
6. 改变雷达高度、俯仰角或通道宽度后，结果能否保持一致；
7. 强反射板引入后，空场虚警和疑似镜像目标的数量及位置如何变化。

## 4. 推荐工具链与处理流程

- CTSAI-A100、稳定支架和 RadarTools：设备配置与数据采集；
- MATLAB：ADC 解包、窗函数、二维 FFT、MTI、CFAR 和结果绘图；
- Python（可选）：CSV/ASC 整理、时间戳对齐、轨迹统计和批量生成图表；
- 卷尺、地面胶带与固定机位相机：记录可复测的场景几何和人工真值。

推荐处理顺序为：

```text
复测通道与安装参数
  -> 采集 W0 空场基线
  -> 依次采集 W1～W6 并重复三次
  -> 校验时间戳、配置文件和数据文件清单
  -> 绘制距离/速度时间序列及目标轨迹
  -> 对 ADC 执行 Range FFT、Doppler FFT、MTI 与 CFAR
  -> 按场景比较漏检、虚警、轨迹中断和多径现象
  -> 记录限制与异常样本
```

现场记录可以使用以下最小表头。距离统一使用米，角度使用度，时间使用带时区的 ISO 8601 格式；未知值保持为空。

```csv
record_id,scene_id,repeat_index,start_time,radar_height_m,yaw_deg,pitch_deg,aisle_width_m,target_type,target_action,radar_config,data_file,ground_truth_file,notes
W0-R01,W0,1,,,,,,,,,,,
W1-R01,W1,1,,,,,,person,approach,,,,
```

## 5. 结果评价建议

空场数据可统计出现非背景目标的帧比例。动态场景可记录有效轨迹覆盖人工动作时长的比例、距离趋势是否符合靠近或远离方向、目标中断持续时间，以及两目标场景中的轨迹交换次数。静止纸箱和人员停留需要分别查看未做 MTI 与做过 MTI 的结果，避免把 MTI 后能量下降误判为障碍物消失。

不同场景之间应使用相同坐标范围、色标和检测参数；如果必须修改阈值，应在结果中记录修改原因。参数调优数据与最终验证数据要分开，防止在同一组样本上调参后又将其作为独立验证。

## 6. 注意事项与能力边界

- 实验必须在封闭或受控区域进行，并安排现场人员管理通道；本文不是机器人安全认证方案；
- 金属货架、地面和反射板可能产生多径，镜像点不能未经核验就标记为真实障碍物；
- 雷达测得的是径向运动分量，横向目标即使移动较快，径向速度也可能接近零；
- MTI 会抑制零多普勒附近的能量，不适合单独用于判断静止障碍物是否存在；
- 采集期间不要移动雷达或支架。若姿态改变，应创建新的环境编号并重新采集空场基线；
- 结果受配置、安装、目标材质、姿态和环境影响，不应写成探测距离、准确率或安全停车能力承诺；
- 发布照片、视频和日志前应清理人脸、姓名、工牌、仓位号及其他敏感信息。
