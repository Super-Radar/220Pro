# 室内出入口采集会话初始化工具设计

现有本地 ADC 目录均属于此前的小推车和纸箱实验，不能据此填写人员出入口 S0～S6 清单。本工具只为下一次独立采集建立记录目录，不复制旧数据，也不自动推断场景标签或实测参数。

脚本使用 Python 标准库实现。调用者必须提供 `--output`，可选提供 `--environment-id`；工具从仓库模板目录读取场地表和采集表，在输出目录创建 `site.csv`、`captures.csv` 与 `README.txt`，并将两张表中的环境编号同步替换为指定值。环境编号只允许字母、数字、点、下划线和连字符。

安全边界为“只创建，不覆盖”。如果输出目录已经包含任一目标文件，脚本在写入前退出；模板缺失、表头不符合预期或两张表的环境编号不一致时同样退出。脚本不修改仓库模板，不扫描 RadarTools 数据目录，不复制 ADC、点云、目标或视频文件。

验证使用临时目录执行：检查三个文件均创建成功；两张 CSV 可解析且环境编号一致；21 条采集记录与 S0～S6 场景覆盖保持不变；第二次对同一目录执行必须失败，并且原文件内容不发生变化。文档给出 Windows 和通用命令示例，输出目录使用仓库外路径，避免误把现场数据加入 Git。
