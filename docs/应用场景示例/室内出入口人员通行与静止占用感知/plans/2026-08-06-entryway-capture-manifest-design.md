# 室内出入口采集清单设计

本次补充只定义现场记录格式，不填入尚未获得的测量值，不导入其他工程的数据，也不把理论场景标签写成实测结论。模板采用 UTF-8 CSV，便于使用文本编辑器、LibreOffice Calc、Python 或 MATLAB 读取。

记录分为场地表和采集表。场地表以 `environment_id` 为主键，保存雷达安装高度、偏航角、俯仰角、近端距离、远端距离、走廊宽度和门宽等同一批实验共享的信息。采集表以 `record_id` 为主键，并通过 `environment_id` 关联场地表；每行对应一次连续采集，保存 S0～S6 场景编号、重复序号、人工动作标签、时间、数据类型、配置文件和数据文件位置。

模板预置 S0～S6 各三次记录及其设计动作，但所有现场尺寸、时间、软件版本和文件路径保持为空。文件路径统一使用相对路径和正斜杠，公开前使用匿名参与者编号，不记录姓名、学号、设备序列号或可识别视频信息。

验证包括：两张 CSV 可由 Python 标准库解析；表头无重复字段；`record_id` 唯一；场景编号只包含 S0～S6；每个场景恰有三条空白记录；采集表引用的 `environment_id` 存在于场地表；未测量的数值字段保持为空。正文只说明填写方式，不声称模板内容已经完成现场采集。
