# 室内出入口科学示意图设计

本轮只制作与当前场景草案对应的新图，不复用 `a100-indoor-cart-mti` 工程的实测结果。图片采用白底、低饱和配色、统一线宽和数学符号，PNG 用于 Markdown 展示，SVG 用于后续编辑。未测量的走廊宽度、远端距离和安装角只写成 $W_c$、$d_f$ 和 $\theta$，不得赋予虚构数值。

第一张图为 S0～S6 场景矩阵。每个子图使用相同的雷达原点、走廊边界、近端线和远端线，只改变目标位置与运动箭头，用于对照空场、靠近、远离、静止、停止后继续、横向经过和靠近后折返。

第二张图为理想距离—时间曲线。曲线只表达实验动作的运动学约束：靠近满足 $\mathrm{d}r/\mathrm{d}t<0$，远离满足 $\mathrm{d}r/\mathrm{d}t>0$，静止段斜率近似为零，折返在转向时刻改变斜率符号。坐标轴使用归一化时间和符号距离，不解释为实测轨迹。

第三张图为室内多径几何。图中同时绘制直达路径、墙面一次反射路径和镜像目标，并给出 $L_d$、$L_r$ 以及表观距离偏差 $\Delta R=(L_r-L_d)/2$，说明墙体可能产生墙后点或贴墙假轨迹。

每张图由独立 Matplotlib 脚本生成。验证包括脚本可重复执行、PNG/SVG 均存在、SVG 无尾随空格、图片目视检查无文字遮挡，以及 Markdown 相对链接可解析。
