# 室内走廊人员横向穿越与速度测量实验

## 1. 场景背景

室内走廊是办公楼、教学楼和实验室中常见的人员通行场景。人员可能沿走廊纵向移动，也可能从房间、门口或岔路处横向穿越雷达视场。相比单纯判断“是否有人”，对目标运动方向、速度变化和轨迹连续性进行观察，更适合作为毫米波雷达基础感知能力的实验验证场景。

本示例以 CTSAI-A100 为实验设备，设计一个可重复的室内走廊人员横向穿越实验。实验重点是记录人员穿越过程中产生的点云或目标数据，观察目标速度、轨迹以及目标编号的变化。本示例仅提供研究和实验流程，不代表产品性能测试结果，也不构成实际安防或商业部署方案。

## 2. 场景布置

选择一段人员较少、地面平整且能够安全通行的室内走廊。将 CTSAI-A100 固定在走廊一侧，避免实验过程中设备位置发生变化。在雷达前方划定测试区域，并分别标记人员的起点、穿越区域中心和终点。

建议的场景示意如下：

```text
走廊左侧起点  --------  测试区域中心  --------  走廊右侧终点
                              |
                         CTSAI-A100
```

实际距离、安装高度和雷达朝向应根据实验场地及设备文档确定，并在每次实验记录中注明。不要在没有实测依据的情况下将某一组安装参数描述为最佳参数。

## 3. 数据类型

本实验主要使用以下数据：

- 点云或目标级数据：用于观察目标位置、运动速度、目标编号和轨迹连续性。
- ADC 数据（可选）：适合需要进一步研究原始信号处理算法的实验。
- 实验元数据：包括测试时间、场地、雷达位置、人员运动方向、重复次数和异常情况。

使用 RadarTools 导出 CSV 数据后，可以重点观察 `target_id`、`velocity_mps` 等字段。其他字段名称和含义应以当前软件实际导出的 CSV 文件及仓库文档为准，不应凭空补充不存在的字段。

## 4. 研究问题

本场景可以用于研究以下问题：

1. 人员从左向右和从右向左穿越时，速度变化是否能够被连续记录。
2. 单次穿越过程中，目标编号是否保持稳定，是否出现轨迹中断或编号切换。
3. 人员停止后再次移动时，目标能否重新形成连续轨迹。
4. 不同运动速度和不同穿越位置是否会影响数据完整性。
5. 走廊墙壁、门框、金属物体等环境因素是否会引入静态杂波或多径反射。
6. 多次重复实验的数据分布是否具有一致性。

## 5. 实验工具链

建议使用以下软硬件完成实验：

- CTSAI-A100 毫米波雷达。
- USB-CAN FD 设备及连接线。
- Windows 计算机和 RadarTools 上位机。
- Python 3 数据处理环境。
- 仓库提供的 Python 可视化示例。
- 卷尺、地面标记胶带和实验记录表。
- 手机计时或录像设备（可选，仅用于独立参考，使用时应注意个人隐私）。

## 6. 实验过程

### 6.1 空场采集

1. 完成设备连接并启动 RadarTools。
2. 确认测试区域内无人移动。
3. 采集一段空场数据，作为环境背景参考。
4. 记录雷达安装位置、朝向以及附近可能产生反射的物体。

### 6.2 单人横向穿越

1. 测试人员站在走廊左侧起点。
2. 以自然步行速度经过测试区域，到达右侧终点。
3. 保存该次实验数据，并记录运动方向和开始时间。
4. 按照相同路线重复若干次。
5. 将运动方向改为从右向左，重复相同步骤。

为了便于比较，建议每一种方向至少重复 5 次，但实际次数可以根据实验条件调整。

### 6.3 停止与重新移动

1. 测试人员从起点进入测试区域。
2. 在测试区域中心短暂停留。
3. 停留后继续向终点移动。
4. 观察停止和重新移动前后目标编号及轨迹是否连续。
5. 重复实验并记录出现轨迹中断的情况。

### 6.4 不同速度对比

在确保安全的前提下，可以分别进行慢速步行和正常步行实验。若场地狭窄或地面湿滑，不应进行快速奔跑测试。

## 7. 数据分析方法

完成数据采集后，可以通过 RadarTools 或 Python 示例程序进行可视化和统计分析。

建议分析以下指标：

- 轨迹连续性：目标在一次完整穿越过程中是否持续被记录。
- 编号切换次数：单次穿越过程中 `target_id` 发生变化的次数。
- 速度稳定性：对单次实验中的有效速度数据计算中位数、最大值、最小值或四分位距。
- 重复性：比较相同方向多次实验的速度曲线和轨迹形态。
- 异常点数量：统计明显偏离主要轨迹的数据点，并结合现场环境分析可能原因。

如果没有经过标定的独立参考设备，只能分析雷达测量结果的一致性，不应直接宣称速度测量的绝对误差或准确率。若需要计算绝对误差，应同时使用经过验证的参考测量方法，并说明时间同步和误差计算过程。

## 8. 文件与实验记录建议

建议按照“日期、方向、次数”的方式保存数据，例如：

```text
20260907_left_to_right_01.csv
20260907_left_to_right_02.csv
20260907_right_to_left_01.csv
20260907_stop_and_go_01.csv
```

每组实验至少记录以下信息：

| 项目 | 记录内容 |
| --- | --- |
| 实验日期 | 实际采集日期 |
| 测试场地 | 走廊或实验室位置 |
| 运动方向 | 左到右、右到左或停止后移动 |
| 重复编号 | 第几次重复实验 |
| 雷达位置 | 安装位置和大致朝向 |
| 数据文件 | 对应的 CSV 或 ADC 文件名 |
| 异常情况 | 临时人员经过、遮挡、连接中断等 |

## 9. 注意事项

- 在走廊中进行实验时，应避免影响其他人员正常通行。
- 设备和连接线应固定，防止绊倒人员或导致设备跌落。
- 每次改变雷达位置或参数后，应重新记录实验配置。
- 走廊墙壁、门框和金属设施可能产生多径反射，分析结果时需要考虑环境影响。
- 如果使用录像作为参考，应提前获得参与者同意，并避免公开人脸、姓名等个人信息。
- 提交公开数据前，应检查文件中是否包含个人信息、设备序列号或其他不适合公开的内容。
- 在尚未完成实测前，应将输出描述为“预期观察内容”，不得将其表述为已经得到验证的实验结论。

## 10. 预期输出

完成实验后，预期可以形成以下材料：

- 不同运动方向的原始数据文件。
- 人员横向穿越过程的轨迹或速度曲线。
- 各次实验的目标编号切换和轨迹中断记录。
- 不同实验条件下的数据对比表。
- 对异常数据、静态杂波和多径现象的初步分析。

这些材料可以用于学习 CTSAI-A100 的数据采集和可视化流程，也可以作为后续目标跟踪、运动状态识别和多目标实验的基础。
