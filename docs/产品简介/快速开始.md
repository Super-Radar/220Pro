### 硬件准备

使用前请准备以下硬件：

| 类型   | 名称                | 说明                      |
| ---- | ----------------- | ----------------------- |
| 雷达硬件 | CTSAI-A100 | 毫米波雷达     |
| 电源   | 12V DC 电源         | 雷达典型工作电压为 +12V DC       |
| 通信设备 | USB-CAN FD 盒      | 用于 PC 与雷达之间的 CAN-FD 通信  |
| 线束   | 雷达连接线束            | 包含电源线与 CAN 通信线          |
| 电脑   | Windows PC        | 用于运行 RadarTools、采集数据和调试 |
| 可选设备 | 标定板 / 反射锥 / 三角反射器 | 用于雷达标定与目标测试             |
| 可选设备 | 三脚架 / 固定支架        | 用于雷达固定和实验平台搭建           |

### 软件准备

[请从 SuperRadar GitHub 仓库下载以下资源：](https://github.com/Super-Radar/CTSAI-A100)

其中：

- `RadarTools/RadarTools_Release/`：用于雷达连接、波形切换、点云显示、点云采集和 ADC 数据采集。
- `USBCAN盒驱动/`：用于安装 USB-CAN FD 设备驱动。
- `Python雷达可视化工具示例/`：包含 Python 可视化脚本和示例 CSV 数据。
- `ADC数据采集/matlab_signal_processing_platform_231023_for_txt_A100/`：包含 ADC 数据处理示例和示例数据。

当前仓库未包含独立的 RadarTools 标定程序。



### 接线与通电

完成如下连接：

1. 给设备通电  
2. 将 CAN 线接入 USBCAN 盒  
3. 按如下方式连接：
   - `PCAN-L` → `CAN1 L`
   - `PCAN-H` → `CAN1 H` 

建议首次调试时在相对开阔、目标清晰的环境中进行。

### USBCAN 驱动

根据电脑系统位数安装对应驱动：
- 32 位系统：`DPInst32.exe`
- 64 位系统：`DPInst64.exe`
驱动安装成功后，可在设备管理器中看到对应的 USBCAN 设备。

### 启动 RadarTools

下载安装部署 `RadarTools`：

运行 `RadarTools/RadarTools_Release/RadarTools_V1.4.7.1.exe`。
在确认连接参数配置正确后，点击 `Start` 启动设备。

启动成功后，你应当能够在界面中看到：
- 原始点
- 跟踪点
- 目标列表
- 角度 / 距离显示区
