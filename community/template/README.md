# A100 Community Project Template

本目录是 **CTSAI-A100 社区项目提交模板**。

如果你基于 CTSAI-A100 完成了算法实验、数据分析、场景测试或应用开发，欢迎将成果贡献到 A100 Community Projects。

社区希望每个项目不仅能够展示结果，也尽可能让其他开发者能够：

> **看得懂、跑得起来、可以继续开发。**

---

## 1. 可以贡献什么？

包括但不限于：

* ADC 信号处理与分析
* Range FFT / Doppler FFT / 2D FFT
* MTI、CFAR 等雷达算法实验
* 点云处理、聚类与目标跟踪
* MATLAB / Python 开发实践
* AI 感知与模型验证
* 机器人环境感知
* 低空目标探测
* 真实场景测试
* 其他基于 CTSAI-A100 的应用项目

---

## 2. 项目提交到哪里？

请在以下目录中创建自己的独立项目：

`community/projects/<project-name>/`

例如：

`community/projects/human-mti/`

项目名称建议使用简短、清晰的英文名称。

---

## 3. 一个项目至少需要包含什么？

每个项目至少需要提供：

### 项目说明

整体技术文档说明：

* 项目做什么
* 使用什么场景
* 解决什么问题

### 开发环境

说明：

* 使用的雷达：CTSAI-A100
* RadarTools / 固件版本（如适用）
* 操作系统
* MATLAB、Python 或其他开发环境及版本

### 数据说明

说明：

* 使用 ADC、点云还是其他数据
* 数据如何采集
* 数据格式
* 数据如何获取

### 项目代码

提供项目运行所需的主要代码，例如：

* MATLAB
* Python
* C / C++
* ROS
* Jupyter Notebook

并明确说明主要运行入口。

### 运行方法

请尽可能按照步骤说明：

1. 需要准备什么
2. 如何配置环境
3. 如何加载数据
4. 运行哪个程序
5. 如何查看结果

### 结果展示

请提供能够说明项目实际运行效果的结果，例如：

* Range FFT
* 2D FFT
* Range-Doppler Map
* MTI 前后对比
* CFAR 检测结果
* 点云可视化
* 目标轨迹
* 算法输出
* Demo 截图

并对关键结果进行简单说明。

### 作者信息

请注明：

* 作者或团队名称
* GitHub 用户名
* 其他希望公开的信息

---

## 4. 最低提交标准

提交 Pull Request 前，请至少确认：

* [ ] 项目基于 CTSAI-A100 开发
* [ ] 有完整的项目介绍
* [ ] 有可以查看或运行的主要代码
* [ ] 已说明使用的数据及来源
* [ ] 已说明开发环境和运行方式
* [ ] 有实际运行结果或实验结果
* [ ] 已注明作者或团队信息
* [ ] 项目位于 `community/projects/<project-name>/`

我们希望项目是真实完成的开发实践，而不是只有概念、PPT 或项目设想。

---

## 5. 关于数据

如果项目数据量较小，可以随项目提供示例数据。

如果数据暂时无法公开，也请说明其他开发者如何使用自己的数据复现实验。

请勿上传没有公开授权的数据、代码或其他受限制内容。

---

## 6. 请不要修改官方资源

Community Project 主要用于新增开发者自己的项目。

除非 SuperRadar 官方明确邀请，请不要修改 A100 仓库中的官方资源，例如：

* RadarTools
* USB-CAN 驱动
* 官方 ADC 数据采集资源
* 官方 Python / MATLAB 基础示例
* 官方产品文档

如果发现官方资源存在问题，请优先通过 GitHub Issue 反馈。

---

## 7. 一个好的 Community Project

我们希望一个项目能够回答五个问题：

**你做了什么？**

**使用了什么数据？**

**怎么实现的？**

**得到了什么结果？**

**其他开发者怎么复现？**

这才是一个有价值的 A100 Community Project。

## 项目目录组织方式

每个开发者提交的成果，应作为一个完整项目统一放在自己的项目文件夹中。

例如：

community/projects/a100-human-mti/

该目录应包含这个项目相关的代码、数据说明、实验结果、图片和文档等全部内容。

推荐结构：

community/projects/a100-human-mti/
├── README.md
├── src/
├── data/
├── figures/
└── docs/

其中：

- README.md：项目介绍、环境、运行方法和结果说明
- src/：项目代码
- data/：项目数据或数据获取说明
- figures/：实验结果、效果图和可视化图片
- docs/：其他实验文档，可选

不同项目可以根据实际情况调整目录，但项目相关内容应尽量集中在自己的项目文件夹中，不要散落到 A100 仓库其他目录。
