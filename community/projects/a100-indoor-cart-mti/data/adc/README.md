# CTSAI-A100 实测 ADC 数据说明

本目录保存 2026-08-02 在室内房间采集并确认有效的 CTSAI-A100 ADC 文本数据。它们是硬件实测，不是仿真数据。项目中的 LFMCW 教学仿真位于代码层，和这里的原始文件严格分开。

## 有效数据集

| 目录 | 场景 | 接收通道 | 用途 |
| --- | --- | --- | --- |
| `adc_test_20260802162041191/` | 静止塑料目标 | Rx0–Rx3 | 四通道静态目标、背景杂波与距离 bin 对比 |
| `adc_empty_background_20260802162429496/` | 空场背景 | Rx0–Rx3 | 四通道底噪和静态背景参考 |
| `adc_approaching_box_rx0_20260802163233093/` | 小推车/箱子靠近 | Rx0 | 原始 2D-FFT 与 MTI 尝试 |
| `adc_receding_box_rx0_retry3_20260802164502658/` | 小推车/箱子远离 | Rx0 | 最终有效远离版本 |

静止目标由采集者记录为塑料材质，约 `1.00 m × 0.80 m`。雷达中心离地约 `0.95 m`，采用倾斜安装，但没有测量倾角。

## 文本格式

每个文件都是十进制数值文本，前三个字段不是 ADC 样本：

1. 接收通道号；
2. 每个 chirp 的采样数 `1024`；
3. chirp 数 `256`。

其后才是打包的 ADC 数据。每个无符号 32 位字包含两个有符号 16 位样本，因此有效打包字数必须为：

```text
1024 × 256 ÷ 2 = 131072
```

本批有效文件在 131072 个打包字后还有一个零填充字段。加载器只在确认全部多余字段都等于零后才截取；短文件、错误头字段、通道名与头部不一致、非零多余字段均会报错。拆包后矩阵尺寸固定为 `1024 × 256`，行是快时间采样，列是慢时间 chirp。

项目加载器：

- `src/load_a100_adc.m`
- `src/unpack_a100_words.m`

对应测试：

- `tests/test_adc_loader.m`
- `tests/test_upstream_loader.m`

## 分析边界

当前文本采集没有提供一套可独立核验的完整调频斜率、ADC 采样率、chirp 时序、发射 DDMA 相位编码及通道标定参数。因此，本项目对 ADC 只输出：

- ADC RMS；
- 距离 bin 频谱；
- 归一化多普勒频率（cycles/chirp）；
- 距离 bin—归一化多普勒图；
- MTI 前后零多普勒邻域变化。

这些图不能直接解释为准确的米和米每秒。真实目标距离和运动趋势使用 `data/targets/` 中的 RawTarget/TraTarget 输出交叉验证。
