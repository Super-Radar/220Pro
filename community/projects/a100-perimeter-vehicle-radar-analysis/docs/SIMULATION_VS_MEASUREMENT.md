\# MATLAB 仿真与 CTSAI-A100 实测结果对比



\## 1. 对比目的



本项目同时包含 MATLAB LFMCW 仿真和 CTSAI-A100 ADC 实测数据分析。



仿真的主要作用是提供可控的目标距离、速度、目标数量和雷达参数，从而观察不同参数对 LFMCW、Range-Doppler 和 MTI 结果的影响。



实测数据则用于展示真实 CTSAI-A100 数据中的信号、杂波和运动目标特征。



两部分结果用于定性和特征级对比，而不是进行严格的一一数值拟合。



\## 2. 静态背景



MATLAB 仿真中人为设置多个零速度静态反射体。



在未进行 MTI 的 Range-Doppler Map 中，可以观察到零 Doppler 附近明显的静态杂波响应。



CTSAI-A100 实测数据中，空环境以及车辆场景同样包含明显的静态和近静态背景分量。



因此，仿真与实测均能观察到零 Doppler 附近较强的背景能量。



\## 3. MTI 对比



实测部分选择零 Doppler 中心附近约 ±0.32 m/s 作为近零 Doppler 能量分析区域。



三个代表性 Rx0 样本得到：



| Scene               | MTI2 suppression | MTI3 suppression |

| ------------------- | ---------------: | ---------------: |

| Empty               |         42.90 dB |         68.37 dB |

| Vehicle approaching |         43.68 dB |         69.76 dB |

| Vehicle receding    |         42.23 dB |         67.70 dB |



结果表明，二脉冲和三脉冲差分型 MTI 均能明显降低近零 Doppler 能量，其中 MTI3 的抑制作用更强。



仿真中的 MTI 实验也表现出相同的基本趋势：静态杂波经过 MTI 后受到明显抑制，而具有非零 Doppler 的运动目标响应可以得到保留。



需要注意，上述抑制量用于表示本实验定义的近零 Doppler 能量变化，不应直接解释为 CTSAI-A100 产品的统一静态杂波抑制性能指标。



\## 4. 运动目标



仿真中的车辆使用理想点目标模型，目标初始距离和径向速度均为已知值。



因此 Range-Doppler 图中的目标响应位置较为清晰，并且能够直接观察目标速度变化带来的 Doppler 位置变化。



真实车辆不是单一理想点目标。



车辆车身、车轮、玻璃、金属结构等均可能形成不同散射中心，同时真实环境中还存在地面、建筑和其他物体的反射以及多径效应。



因此实测 Range-Doppler Map 通常比理想仿真更加复杂。



\## 5. 仿真与实测主要差异



\### 仿真



\* 目标距离已知

\* 目标速度已知

\* 目标运动连续

\* 静态杂波位置和幅度人为设置

\* 噪声模型可控

\* 可以单独改变一个参数并观察影响



\### 实测



\* 车辆属于扩展目标

\* 存在多个散射中心

\* 存在真实环境杂波

\* 存在多径和系统噪声

\* 未使用理想点目标假设

\* 本次车辆采集不是严格连续的运动轨迹



因此，仿真结果更适合用于解释 LFMCW 信号处理原理和参数影响，而实测结果用于验证真实 CTSAI-A100 数据中是否能够观察到对应的雷达特征。



\## 6. 实测采集限制



本次数据采用 ALL channel 方式采集。



由于当前数据采集和保存速度较慢，单个 RX 的一帧数据需要十几秒左右。因此车辆靠近和车辆远离场景中的 5 个 run 应理解为离散场景样本，而不是连续等时间间隔的车辆运动轨迹。



同样，Rx0-Rx3 数据不被假设为运动车辆完全同一时刻的严格同步阵列快照。



因此本项目不使用这些 run 重建连续车辆轨迹，也不利用这批数据声明严格的四通道相干角度估计结果。



\## 7. 结论



MATLAB 仿真和 CTSAI-A100 实测数据均能够展示：



\* Range FFT 特征

\* Range-Doppler / 2D-FFT 特征

\* 静态背景的零 Doppler 响应

\* MTI 对静态和近静态分量的抑制作用

\* 运动目标对应的非零 Doppler 特征



MATLAB 仿真进一步用于研究带宽、chirp duration、PRF、目标数量、目标速度和 MTI 阶数变化。



实测数据则反映真实车辆、真实环境杂波和实际数据采集流程下更加复杂的雷达响应。



因此，本项目将仿真结果用于原理和参数规律分析，将实测结果用于真实场景特征展示，并明确区分两者与 CTSAI-A100 产品实际能力之间的边界。
