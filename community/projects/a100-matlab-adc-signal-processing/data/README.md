## Data Source

The example dataset was collected from a CTSAI-A100 radar and is included for demonstrating the MATLAB ADC signal-processing workflow.

The dataset contains four receive-channel ADC TXT files (Rx0-Rx3) for profile Pf0. Users can also replace these files with their own compatible CTSAI-A100 ADC data to reproduce the processing pipeline.

The example data is provided only for project demonstration and algorithm validation.
