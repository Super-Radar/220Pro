# A100 Community Projects

这里收录开发者基于 **CTSAI-A100** 完成的社区项目、算法实验与应用案例。

每个项目使用独立目录进行管理，例如：

```text
community/projects/
├── human-mti/
├── 2dfft-demo/
├── pointcloud-tracking/
└── robot-perception/
```

## 项目说明

社区项目可能包括：

* ADC 信号处理与分析
* Range FFT / Doppler FFT / 2D FFT
* MTI / CFAR 等算法实验
* 点云处理、聚类与目标跟踪
* MATLAB / Python 开发实践
* AI 感知与模型验证
* 机器人、低空及其他实际场景应用

每个项目应尽可能提供代码、数据说明、实验环境、运行方法和结果展示，方便其他开发者理解、复现和继续开发。
