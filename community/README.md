# A100 Community

这里用于收录开发者基于 **CTSAI-A100** 产生的社区项目、算法实验、应用案例与开发实践。

你可以在这里：

* 查看其他开发者基于 A100 完成的项目
* 学习 ADC、点云、MATLAB、Python 等开发实践
* 参考真实场景下的实验方法和结果
* 提交自己的 A100 Community Project

## Community Projects

社区项目统一收录在：

`community/projects/`

项目可以包括：

* 雷达信号处理
* ADC 数据分析
* Range FFT / Doppler FFT / 2D FFT
* MTI / CFAR 等算法实验
* 点云聚类与目标跟踪
* AI 感知
* 机器人感知
* 低空目标探测
* 其他基于 CTSAI-A100 的应用实践

## 参与贡献

开发者可以通过 Pull Request 提交自己的项目。

项目统一提交至：

`community/projects/<project-name>/`

后续请按照项目模板准备代码、文档、数据说明和实验结果。
